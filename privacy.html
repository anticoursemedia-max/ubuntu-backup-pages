Политика конфиденциальности

Действует с 1 ноября 2026 года

Ubuntu Backup — личный инструмент владельца аккаунта для резервирования файлов и доступа к Google Диску с ноутбука Ubuntu. Эта политика описывает работу данного инструмента.

Какие данные обрабатываются и зачем

Локально обрабатываются выбранные владельцем файлы и настройки для создания и проверки резервных копий. При работе с Google Диском rclone получает метаданные файлов, включая имена, идентификаторы, размеры и контрольные суммы, а также содержимое файлов при чтении, загрузке и проверке. Эти данные используются для резервирования и работы подключённой папки.

Разрешение Google Drive позволяет читать, создавать, изменять и удалять файлы в аккаунте владельца. Оно применяется к файлам аккаунта, а не только к новым резервным копиям.

Где хранятся данные

Резервные архивы шифруются restic на ноутбуке до отправки на Google Диск. Обычные файлы Google Диска, доступные через подключённую папку, не получают это шифрование автоматически и могут временно храниться в локальном кеше rclone.

Токены OAuth хранятся в локальном конфигурационном файле rclone. Настройки, включая авторизационные данные, могут включаться в зашифрованные резервные копии. Ключ восстановления резервов хранится владельцем отдельно от архивов.

Передача и использование данных

Данные передаются между ноутбуком и Google Drive API для выполнения действий владельца. У инструмента нет отдельного сервера разработчика для обработки содержимого файлов. Инструмент не продаёт данные и не использует их для рекламы.

Использование и передача сведений, полученных через API Google, соответствуют Google API Services User Data Policy, включая требования Limited Use.

Сроки хранения, удаление и отзыв доступа

Сроки хранения определяет владелец. Он может удалить резервные копии и файлы средствами локальной системы резервирования и Google Диска, а также очистить локальный кеш.

Доступ приложения можно отозвать в настройках подключений аккаунта Google. Отзыв доступа прекращает дальнейшее обращение приложения к API, но сам по себе не удаляет ранее сохранённые файлы и резервные копии.
