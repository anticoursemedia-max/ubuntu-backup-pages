Ubuntu Backup

Ubuntu Backup — настройка личного ноутбука для создания зашифрованных резервных копий и работы с собственным Google Диском. Приложение используется владельцем аккаунта.

Что делает приложение

  • Создаёт локальные резервные копии выбранных файлов и настроек с помощью restic.
  • Проверяет резервные копии и отправляет зашифрованные архивы на Google Диск с помощью rclone.
  • Позволяет работать с файлами Google Диска через подключённую папку на ноутбуке.

Доступ к Google Диску

Разрешение Google Drive позволяет просматривать список файлов, читать, создавать, изменять и удалять файлы в аккаунте владельца. Доступ нужен для резервирования, проверки загрузок и работы подключённой папки. Разрешение выдаётся через Google OAuth.

Условия использования

Инструмент предназначен для личного использования владельцем аккаунта. Владелец выбирает файлы для резервирования, управляет сроками хранения и хранит ключ восстановления. Доступ можно отозвать в настройках аккаунта Google.
